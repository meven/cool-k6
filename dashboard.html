k6-flamegraph metrics

Each test scenario has its own charts of CPU instructions and peak memory per run. Click any point to open that run's flamegraph.

coolwsd + forkit document kit
Runs are grouped by their k6 test scenario. Two measures of different scale get their own panel rather than a shared axis. Series colours are a fixed colourblind-safe pair and every point is labelled, so identity and value never rely on colour alone. Each point opens the flamegraph.svg from that run's output directory.
